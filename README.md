# CITwinkler

新增一个容器组件，能使包含的子组件有描边闪烁效果。

# 新内容

添加了"闪烁内容"组件，能使包含的子组件有描边闪烁效果；  
添加行动"闪烁"，通过触发器来使已有的"闪烁内容"组件触发闪烁效果。  

# ~~富含~~可自定义内容

### "闪烁内容"组件

可设定闪烁时的描边颜色、渐变描边颜色、描边粗细等；  
可设定闪烁时闪烁模式、闪烁循环时间(闪烁速度)、亮度；  
可以添加规则集来限制何时会启用闪烁效果。  

### 行动"闪烁"

与 "闪烁内容"组件 的可自定义内容相似，可以对指定的 "闪烁内容"组件 执行效果。  

# 使用
* **Star it!**
### 安装

打开ClassIsland，点击托盘，打开应用设置-->插件，将Releases发布的.cipx文件拖入CI应用设置的窗口中，确定安装，重启即可安装完成。
