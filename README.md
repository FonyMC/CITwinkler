# CITwinkler

为 ClassIsland 提供两个「描边」容器组件，以及一个配套的自动化行动。

| 名称 | 类型 | 作用 |
|---|---|---|
| 描边渐变闪烁 | 容器组件 | 让子组件内容边缘出现双色渐变描边，并可循环闪烁 |
| 文字描边 | 容器组件 | 用一圈实线紧贴包围子组件实际显示的内容，并可循环闪烁 |
| 闪烁 | 自动化行动 | 通过触发器让指定组件立刻闪烁一下 |

# 新内容

添加了"描边渐变闪烁"组件，能使包含的子组件有描边闪烁效果；  
添加了"文字描边"组件，能用一圈实线包围包含的子组件实际显示的内容；  
添加行动"闪烁"，通过触发器来使已有的描边组件触发闪烁效果。  

# ~~富含~~可自定义内容

### "描边渐变闪烁"组件

在包含的子组件内容字符边缘叠加一层柔和的双色描边，并按循环时间在明暗之间渐变。

| 设置项 | 说明 |
|---|---|
| 启用描边 | 关闭后本组件退化为普通的分组容器 |
| 组件名称 | 仅用于在"闪烁"行动里标识这个组件 |
| 描边颜色 | 描边主色 |
| 渐变描边 | 开启后再指定第二个颜色，内外两层叠加形成颜色过渡 |
| 描边粗细 | 1 ~ 20 px，约等于描边的柔和扩散半径 |
| 闪烁模式 | 循环闪烁 / 保持描边（常亮） |
| 闪烁循环时间 | 一个完整明暗循环所需的秒数，仅在"循环闪烁"模式下生效 |
| 描边亮度范围 | 循环到最暗 / 最亮时的不透明度 |
| 启用规则集限制 | 只有规则集满足时才会显示描边与闪烁 |
| 行动触发时忽略规则集 | "闪烁"行动触发时无视上面的规则集限制 |

### "文字描边"组件

用一圈实线包围容器内组件**实际显示的内容**（不是整个容器），线与内容之间可留出间距。
描边线画在布局之外，因此不会挤压、移动或改变子组件的尺寸。

| 设置项 | 说明 |
|---|---|
| 启用描边 | 关闭后本组件退化为普通的分组容器 |
| 组件名称 | 仅用于在"闪烁"行动里标识这个组件 |
| 描边颜色 | 实线颜色 |
| 描边粗细 | 1 ~ 20 px |
| 描边间距 | 5 ~ 500 px，可拉动滑块或直接输入数值 |
| 闪烁模式 | 循环闪烁 / 保持描边（常亮） |
| 闪烁循环时间 | 一个完整明暗循环所需的秒数，仅在"循环闪烁"模式下生效 |
| 启用规则集限制 | 只有规则集满足时才会显示描边与闪烁 |
| 行动触发时忽略规则集 | "闪烁"行动触发时无视上面的规则集限制 |

> 间距是按像素给的，调大时描边框会超出主界面一行的高度，按需调小即可。

### 行动"闪烁"

配合自动化触发器使用，命中时让目标组件立刻闪烁一段，结束后自动恢复原状态。

| 设置项 | 说明 |
|---|---|
| 作用目标 | 全部可闪烁组件，或勾选指定的组件 |
| 自定义闪烁时长 | 关闭时按"组件循环时间 × 闪烁次数"自动计算总时长 |
| 自定义闪烁次数 | 本次行动过程中描边明暗循环的次数 |
| 覆盖描边颜色 | 启用后本次闪烁改用指定颜色，否则用组件自身设置的颜色 |
| 覆盖描边粗细 | 启用后本次闪烁改用指定描边粗细 |
| 忽略规则集限制 | 即使目标组件的规则集不满足，本次闪烁依然会执行 |

# 使用

* **Star it!**

### 安装

打开 ClassIsland，点击托盘，打开应用设置 --> 插件，将 `.cipx` 文件拖入 CI 应用设置的窗口中，确定安装，重启即可安装完成。

插件 id：`fonyu.citwinkler`
